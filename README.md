# QSMaster Shake.io

<div dir="rtl">

## מה יש כאן

- **`game/`**: המשחק המלא. הקובץ הראשי הוא `index.html`, והתמונות נמצאות בתיקייה `a/`.
- **`app-project/`**: הפרויקט לבניית האפליקציה לאנדרואיד ולאייפון (Capacitor + AdMob).
- **`tools/`**: כלים לחיתוך דמויות חדשות מתמונות של ג'מיני.
- **`branding/`**: הלוגו, אייקון האפליקציה, וגיליונות ממוספרים של הלקוחות והפירות.
- **`CLAUDE.md`**: מדריך מלא לקלוד ולמפתח: איפה כל דבר בקוד, איך מוסיפים דמויות, ומה עוד חסר לפני הפרסום בחנויות.

## איך ממשיכים לעבוד עם קלוד

1. מעלים לקלוד את כל הקובץ `QSMasterShake_handoff.zip`.
2. כותבים לו: "תפתח את הזיפ ותקרא קודם את `CLAUDE.md`".
3. אחרי זה מבקשים את השינויים כרגיל.

## איך מריצים במחשב

</div>

```
python3 -m http.server 8765 --directory game
```

<div dir="rtl">

ואז פותחים בדפדפן את `http://localhost:8765/index.html`.
